01 STRUKTURA SYSTEMU

Architektura aplikacji

Żądanie trafia z hosta do API, a FastAPI łączy się z PostgreSQL po nazwie usługi w sieci Compose.

02 / WARSTWA API

FastAPI

API rejestruje incydenty, udostępnia ich listę i pozwala zmieniać status zgłoszenia. Dokumentacja OpenAPI jest dostępna pod /docs.

Punkt wejścia
api:8000

02 URUCHOMIENIE LOKALNE

Docker i Compose

Dockerfile buduje obraz API. Compose uruchamia API i bazę, zarządza ich siecią oraz zapisuje dane PostgreSQL na nazwanym wolumenie.

TERMINAL / KATALOG PROJEKTU
test -f .env || cp .env.example .env
docker compose config --quiet
docker compose up -d --build
docker compose ps
curl -i http://localhost:8000/health
curl -i http://localhost:8000/ready

Polecenia dla pierwszego uruchomienia z domyślnym portem 8000.

01

Obraz API

Python 3.12 slim, Uvicorn i użytkownik appuser bez uprawnień roota.

02

Kolejność startu

API czeka, aż kontrola pg_isready potwierdzi gotowość bazy. Port API jest dostępny z hosta przez 127.0.0.1.

03

Trwałość danych

Wolumen postgres_data zachowuje dane po docker compose down.
